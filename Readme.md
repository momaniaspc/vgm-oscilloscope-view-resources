# My VGM Oscilloscope View Resources WIP
All the software and sites I personally use to make my oscilloscope views.\
In order to make one, you'll need music files, a way to separate the channels/stems, and then the software to visualize them.\
If you know of any other software/websites I could add here, let me know!

## Oscilloscope View Software

| Software | Note |
| :---: | --- |
| [Corrscope](https://github.com/corrscope/corrscope)  | This is the app I use to render every visualization. |
| [SidWizPlus](https://github.com/maxim-zhao/SidWizPlus) | I haven't tried this one out yet, but after reading the page for it, it seems very interesting. |

## Editing Software

| Software | Note |
| :----------------------: | --- |
| [Davinci Resolve](https://www.blackmagicdesign.com/products/davinciresolve) | I use this to edit the layout in my videos and for editing stems normally.|
|[Audacity](https://www.audacityteam.org/download/) | I use this whenever I need to edit audio a little more heavily. (Effects, frequency passes, vocal isolation, etc.|

## Audio File Websites/Resources

### Sequenced Music 
| Website | Note |
| :---: | --- |
| [Zophar.net](https://www.zophar.net/music) | Usually has the required files I need. Has both sequenced and streamed game rips.|
| [HCS64](https://vgm.hcs64.com/)  | Yeah so this website kinda has All the music. New and old games alike (even PC). Only has the in game files used. |
| [VGM Rips](https://vgmrips.net/packs/) | Has music for everything ripped with the .vgm/.vgz file format. Think Sega Genesis and late 80s/early 90s arcade systems. I use this to download single track files. |

### Streamed Music
| Website | Note |
| :---: | --- |
| [KHInsider](https://downloads.khinsider.com/) | Has a lot of VGM in both MP3 and FLAC. Even has uploads of CDs! Almost 0 Sonic music, though. |
| [Sitting on Clouds](https://www.sittingonclouds.net/) | It's a bit buggy, and you can't download individual tracks, but it has a lot of music.
